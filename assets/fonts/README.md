# Self-hosted fonts

This directory contains the WOFF2 subsets used by the Youhu marketing site.
They replace the previous runtime requests to Google Fonts.

- Cormorant Garamond, variable weight 500–700, from Google Fonts v21
- Manrope, variable weight 400–800, from Google Fonts v20

The files retain the same subset boundaries and `unicode-range` declarations
served by Google Fonts. Both families are distributed under the SIL Open Font
License 1.1; see `OFL-1.1.txt`.
